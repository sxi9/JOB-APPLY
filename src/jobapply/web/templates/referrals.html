Referral drafts

These drafts are safe. Generating and queuing referral drafts never contacts anyone. Approving does not send. Sending a LinkedIn connection request or message is a separate, manual step that is off by default and capped per day — LinkedIn bans accounts for automated outreach, so nothing here reaches a person until a human turns the global referral-send switch on and a run picks up a draft you approved.
About LinkedIn automation risk

LinkedIn detects and bans accounts that send connection requests or messages automatically. This page only lets you review, edit, approve or skip drafts. Even an approved draft is never auto-sent: sending is gated behind a global send switch (off by default), a per-user daily referral cap, the kill switch and active hours, and each message must have been approved individually. Keep volumes low and review every draft before approving.
